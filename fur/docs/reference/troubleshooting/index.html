Risoluzion dai problemis e FAQ

Risolf i problemis plui comuns cun Git, la proprietât dai repository, lis build cence firme, lis credenziâls, lis conessions e il plugin par Claude Code, e cjate lis rispuestis aes domandis frecuentis.

Modifiche su GitHub

Tradusude dal inglês cul jutori de IA. In câs di dubi e vâl la version in inglês.

La plui part dai problemis a vegnin dal ambient dulà che al zire mergecat: dulà che al è instalât Git, cui che al è il proprietari di un repository, cuâl deposit des credenziâls che al ufrìs il sisteme, o cemût che il team al integre lis pull request. Cjate chi sot il messaç che tu viodis.

Git nol è stât cjatât

Il messaç al è Git was not found. Install Git (https://git-scm.com/downloads) or set the path to the git executable in the settings.

mergecat al dopre prime il percors configurât, po git tal PATH, po lis cartelis di instalazion solitis:

/opt/homebrew/bin/git, /usr/local/bin/git, /usr/bin/git.

Lis app inviadis dal Dock o dal Finder no ricevin il PATH de tô shell, e par chel mergecat al cîr ancje tes cartelis di Homebrew. /usr/bin/git al à bisugne dai Xcode Command Line Tools; instaliju cun:

xcode-select --install

%ProgramFiles%\Git\cmd\git.exe, %ProgramFiles(x86)%\Git\cmd\git.exe e %LOCALAPPDATA%\Programs\Git\cmd\git.exe.

Instale Git for Windows, o cjate un Git za instalât in PowerShell:

Get-Command git

/usr/bin/git, /usr/local/bin/git.

Instale Git cul to gjestôr dai pachets, par esempli sudo apt install git, o cjate un Git za instalât cun which git.

Se Git al è instalât di altre bande, imposte il so percors:

ComponentDulà
App desktopImpostazions › Eseguibil di Git; il dialic al mostre la version che al à cjatât
VS Codemergecat.gitPath (vueit: il git.path di VS Code, po lis cartelis solitis)
Rie di comant, servidôr MCPVariabile di ambient MERGECAT_GIT_PATH

Git al rifiude di lei il repository

Il messaç al è Git refuses to read this repository because it is owned by another user, seguît di un comant. Git ti protêç dai repository che a son di un altri account (“dubious ownership”), par esempli suntun disc esterni, une cartele condividude in rêt, une cartele creade di un altri utent, o un volum WSL o di un container.

Se tu ti fidis dal repository, segnilu come sigûr, doprant la cartele dal messaç:

git config --global --add safe.directory "/path/to/repository"

Nol è un repository Git

Not a Git repository: … al vûl dî che la cartele no je dentri di une copie di lavôr di Git. Vierç la cartele principâl dal repository o cualsisei cartele dentri di lui. In VS Code, mergecat al cîr ancje tes sotcartelis de cartele vierte (mergecat.repositoryScanDepth, doi nivei par impostazion predefinide).

Il sisteme al avise che la app no je firmade

Lis build di mergecat no son ancjemò firmadis ni notarizadis. Prime verifiche il file discjariât (viôt Build cence firme), po:

Se macOS al dîs che mergecat nol pues jessi viert parcè che Apple no pues controlâ che nol contegni software malevul:

  1. Prove une volte a vierzi mergecat de cartele Applications.
  2. Vierç System Settings › Privacy & Security.
  3. Scor fin al messaç su mergecat e fâs clic su Open Anyway, po conferme.

Se macOS al dîs che la app e je danezade, il file discjariât al è in cuarantene; dopo vê verificât il checksum tu puedis gjavâ l’atribût di cuarantene:

xattr -dr com.apple.quarantine /Applications/mergecat.app

Se Microsoft Defender SmartScreen al mostre Windows protected your PC, fâs clic su More info, controle il non dal file, po su Run anyway.

Linux nol controle lis firmis des AppImage. Rint eseguibile la AppImage prime di inviâle:

chmod +x mergecat-linux-x86_64.AppImage

Su Linux lis credenziâls no vegnin tignudis a ments

Il messaç al è Nol è stât cjatât nissun servizi pai segrets (GNOME Keyring o KWallet): lis credenziâls a vegnin tignudis dome in memorie e tu varâs di conetiti di gnûf dopo vê tornât a inviâ l’app.

mergecat al cifre lis credenziâls cul deposit des credenziâls dal sisteme e no lis scrîf mai in clâr. Cence un servizi pai segrets lis ten dome in memorie. Instale e sbloche GNOME Keyring o KWallet (la plui part dai ambients desktop a ‘nd includin un), po torne invie mergecat e conetiti di gnûf. Sui sistemis cence un servizi pai segrets, conetiti di gnûf dopo ogni inviament.

Su cualsisei sisteme, Nol è disponibil nissun deposit des credenziâls dal sisteme al à il stes significât, e Lis credenziâls a vegnin tignudis dome in memorie (MERGECAT_MEMORY_CREDENTIALS al è impostât) al vûl dî che la variabile di ambient MERGECAT_MEMORY_CREDENTIALS=1 e je impostade.

Il fetch o il push dai tag nol va

mergecat al eseguìs Git cu lis tôs credenziâls e nol domande mai une password. Se il fetch o il push dai tag no van ben, eseguìs git fetch o git push intun terminâl tal stes repository: se chel al domande une password, configure un credential helper (par esempli Git Credential Manager) o une clâf SSH, po torne prove in mergecat.

Stîi di integrazion messedâts: … pull request a somein integradis cun squash merge…Cualchi pull request e je stade integrade cun squash merge; a comparissin come commit singui

Chest al è un clon shallow…E mancje la storie plui vecje. Eseguìs git fetch --unshallow

Lis aprovazions a son “unknown” tal rapuart di audit

Lis aprovazions a son salvadis dal servizi di hosting. Conet GitHub, GitLab o Azure DevOps prime di esportâ il rapuart; la app desktop e VS Code a proponin di conetisi cuant che tu esportis. La rie di comant no si conet mai, duncje i siei rapuarts a mostrin simpri lis aprovazions come no cognossudis. Viôt Rapuarts di audit des modifichis.

Un ambient al à un commit che nol è tal to clon

La pagjine Deployment lu dîs cuant che un ambient al à un commit che il to clon nol à ancjemò, par esempli dopo di un deployment di une build plui gnove. Fâs clic su Fetch (o eseguìs git fetch) e confronte di gnûf.

I comants di VS Code a fasin alc che no ti spietis

“MergeCat for VS Code” (mergecat.mergecat-vscode) e je une estension dal Marketplace che no à nuie a ce fâ cun mergecat e che e regjistre i stes nons di comants e di impostazions. Gjavile:

code --uninstall-extension mergecat.mergecat-vscode

Plugin par Claude Code

La domande di conformitât e ven fate di gnûf

Al è normâl. La rispueste e je de session di Claude Code: ogni session e invie un gnûf procès dal servidôr MCP di mergecat, che al domande di gnûf prime di mandâ i prins dâts dal repository. Ogni rispueste e je un gnûf regjistri di ûs de IA.

Claude al dîs che e covente une conferme di conformitât

I struments dal repository a son blocâts fin che la domande no à une rispueste cuntun esit che ju permet. Rispuint ae domande cuant che Claude le fâs. Se prime te session tu âs rispuindût “no” a dutis dôs lis domandis, domande di gnûf i dâts di mergecat e Claude al tornarà a fâ la domande.

A mancjin i struments di mergecat

  1. Eseguìs /mcp in Claude Code e controle che il servidôr mergecat al sedi conetût.
  2. Controle che Node.js 20 o plui gnûf al sedi instalât come node: node --version.
  3. Controle che il plugin al sedi instalât: claude plugin list.
  4. Dopo de instalazion o dal inzornament, eseguìs /reload-plugins o invie une gnove session.

Il changelog nol à i titui des pull request

Invie Claude Code cul token dal servizi di hosting dal repository impostât: GITHUB_TOKEN (o GH_TOKEN) par GitHub, GITLAB_TOKEN (o GL_TOKEN) par GitLab, AZURE_DEVOPS_EXT_PAT o AZURE_DEVOPS_TOKEN par Azure DevOps. A vegnin ricognossûts dome i repository su github.com, gitlab.com e Azure DevOps. Viôt Dâts des pull request.

Il PDF al mostre ponts di domande

I PDF a doprin i font standard dal PDF, che a cuvierzin dome il Latin-1. Domande il Markdown pes lenghis scritis cun altris sistemis di scriture. Viôt Jessude PDF.

FAQ

mergecat modifichial il gno repository?

Dome cuant che tu fasis un fetch, tu creis o tu fasis il push di un tag, o tu creis une pull request. Nol fâs mai commit, checkout o merge e nol torne a scrivi nuie. Viôt Sigurece e riservatece.

mergecat mandial il gno codiç di cualchi bande?

La app desktop e VS Code a fevelin dome cul servizi di hosting che tu conetis. Il plugin par Claude Code i mande a Claude i metadâts de storie (messaçs dai commit, nons, indirizis e-mail, datis, nons di branch e di tag, SHA dai commit e, cuntun token, dâts des pull request), dopo de domande di conformitât; i siei struments no mandin il contignût dai file ni i diff. Claude Code stes al pues lei i file dal to progjet cui siei permès.

mergecat aial un account, un servidôr o une telemetrie?

No. mergecat nol à ni account, ni servidôr, ni telemetrie, e nol controle se a son inzornaments.

mergecat funzionial cence rêt?

Sì, par dut ce che nol à bisugne dal servizi di hosting: changeset, diff, filtris, esportazions, branch, tag e rapuarts di audit cence aprovazions.

Parcè domandial il plugin di un account Team o Enterprise?

Tantis organizazions a permetin i dâts aziendâi dome sui account di IA cuvierts di un contrat aziendâl. La domande e il regjistri a documentin chê decision par ogni session. Viôt AI Act UE e NIS2.
