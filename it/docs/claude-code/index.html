Integrazioni

Plugin per Claude Code

Installa il plugin mergecat per Claude Code per elencare i tag e scrivere changelog dai changeset di un branch, con un registro di utilizzo dell'AI per ogni sessione.

Modifica su GitHub

Tradotta dall'inglese con l'aiuto dell'IA. In caso di dubbio fa fede la versione inglese.

Il plugin mergecat permette a Claude Code di leggere la cronologia di un repository raggruppata per integrazione e di trasformarla in elenchi di tag e changelog. Contiene il server MCP di mergecat e due skill, /mergecat:tags e /mergecat:changelog. I changelog sono documenti della conversazione, non file del tuo progetto, a meno che tu non chieda di aggiornare CHANGELOG.md.

AI Act UE e NIS2: domanda posta una volta per sessione, risposta registrata ogni volta

Il plugin invia a Claude dati del tuo repository: messaggi di commit, nomi e indirizzi e-mail degli autori, date, nomi di branch e tag e, con un token GitHub, dati delle pull request. Prima dei primi dati del repository di ogni sessione di Claude Code, Claude chiede se usi un account Claude Team o Enterprise. In caso contrario, chiede se sei a conoscenza dell’AI Act UE (il regolamento europeo sull’intelligenza artificiale) e della direttiva NIS2 e se vuoi procedere comunque; “no” ferma mergecat prima che venga inviato qualsiasi dato del repository.

Il server MCP lo impone: i suoi strumenti per il repository restano bloccati finché la risposta non li consente. Ogni risposta viene salvata come registro di audit sul tuo computer e ti viene consegnata come documento della conversazione. Vedi Registri di utilizzo dell’AI.

Cosa ottieni

ComponenteCosa fa
/mergecat:tagsI tag con data, commit, messaggio, se si trovano sul branch principale e quante modifiche contiene ogni release. Dettagli
/mergecat:changelogUn changelog Keep a Changelog delle modifiche non ancora rilasciate, di una versione, di tutte le release o di un intervallo i cui estremi sono tag, date o commit. Inglese e Markdown per impostazione predefinita; altre lingue e PDF su richiesta. Dettagli
Server MCPStrumenti in sola lettura per changeset, tag, release e bozze di changelog, più gli strumenti di conformità. Claude può usarli anche quando chiedi con parole tue, per esempio “quale pull request ha portato il commit abc1234 in main?”. Riferimento degli strumenti

Requisiti

  • Claude Code con supporto per i plugin.
  • Node.js 20 o successivo, disponibile come node nel PATH: il plugin avvia il server MCP con node.
  • Git, nel PATH o impostato con MERGECAT_GIT_PATH.
  • Facoltativo: un token del servizio di hosting del repository (GITHUB_TOKEN, GITLAB_TOKEN o AZURE_DEVOPS_EXT_PAT) per titoli, etichette e issue collegate delle pull request. Vedi Dati delle pull request.

Installazione

Il repository mergecat è anche un marketplace di plugin per Claude Code chiamato mergecat.

Aggiungi il marketplace da GitHub:

claude plugin marketplace add CERTIFIE/mergecat

Installa il plugin:

claude plugin install mergecat@mergecat

Scarica mergecat-claude-plugin.zip dalla sezione download e decomprimilo in una cartella che intendi conservare (il marketplace viene registrato tramite il suo percorso). Contiene la cartella mergecat-claude-plugin/ con .claude-plugin/marketplace.json e plugins/mergecat/.

unzip mergecat-claude-plugin.zip

Su Windows, in PowerShell: Expand-Archive mergecat-claude-plugin.zip -DestinationPath .

Aggiungi il marketplace dalla cartella decompressa e installa il plugin:

claude plugin marketplace add ./mergecat-claude-plugin
claude plugin install mergecat@mergecat

Dalla radice di un clone del repository mergecat (Node.js 20 o successivo), compila il server MCP:

npm install
npm run mcp:build

Aggiungi il clone come marketplace e installa il plugin:

claude plugin marketplace add /path/to/mergecat
claude plugin install mergecat@mergecat

Avvia Claude Code in un qualsiasi repository Git ed esegui /mergecat:tags, oppure chiedi un changelog con parole tue. In Claude Code, /mcp elenca il server mergecat e il suo stato.

Primo utilizzo in una sessione

Chiedi qualcosa

Esegui /mergecat:tags o /mergecat:changelog, oppure chiedi “changelog da v1.2.0 a oggi”.

Rispondi alla domanda di conformità

Claude chiede se usi un account Claude Team o Enterprise e, in caso contrario, se sei a conoscenza dell’AI Act UE e della NIS2 e vuoi procedere comunque. Rispondi sì o no; le skill indicano a Claude di attendere la tua risposta e di non rispondere mai al posto tuo.

Conserva il registro

Claude ti consegna il registro di conformità come documento della conversazione e ti dice dove è memorizzato sul tuo computer.

Ottieni il risultato

Con l’esito “proceed”, Claude legge la cronologia e consegna l’elenco dei tag o il changelog. Le richieste successive nella stessa sessione non ripetono la domanda.

Documenti della conversazione

Changelog e registri di conformità appartengono alla conversazione: Claude li pubblica come artifact Markdown o li invia come file che puoi aprire e scaricare, oppure li mostra come blocco Markdown nella risposta. Vengono scritti fuori dal tuo repository (nello scratchpad di Claude o nella cartella temporanea di sistema). Solo /mergecat:changelog … update file, o la richiesta a parole di aggiornare CHANGELOG.md, modifica un file del tuo progetto.

Dati delle pull request

Senza token, gli strumenti usano solo i dati Git locali: changeset, nomi dei branch integrati ricavati dai messaggi di merge, tag. Imposta il token del servizio di hosting del repository nell’ambiente da cui avvii Claude Code per aggiungere titoli, etichette e issue collegate delle pull request (merge request), che rendono migliori le sezioni e le righe del changelog: GITHUB_TOKEN (o GH_TOKEN) per GitHub, GITLAB_TOKEN (o GL_TOKEN) per GitLab, AZURE_DEVOPS_EXT_PAT o AZURE_DEVOPS_TOKEN per Azure DevOps (vedi Server MCP e strumenti).

export GITHUB_TOKEN=...   # a token that can read the repository's pull requests
claude

Vengono riconosciuti solo i repository su github.com, gitlab.com e Azure DevOps. Per gli host GitHub e GitLab self-managed, usa l’app desktop o VS Code.

Aggiornamento

Dopo una nuova release (scarica e decomprimi il nuovo zip nella stessa cartella) o una nuova build:

claude plugin marketplace update mergecat
claude plugin update mergecat@mergecat

Poi esegui /reload-plugins in Claude Code, oppure avvia una nuova sessione.

Disinstallazione

claude plugin uninstall mergecat@mergecat
claude plugin marketplace remove mergecat

I registri di conformità restano sul tuo computer; vedi dove sono memorizzati.

Prossimi passi
